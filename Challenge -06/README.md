# SMARTCAMPUS

## About the Project
SMARTCAMPUS is a C programming project that works with an array of readings and performs different calculations and operations on them.

The program accepts 5 to 12 readings, with each reading between 0 and 1000, and displays the results.

## Features
- Calculates the sum and average of readings.
- Finds the minimum and maximum values.
- Finds the second-largest distinct value.
- Counts the number of local peaks.
- Finds the longest strictly increasing run.
- Rotates the array to the right by K positions.
- Counts values divisible by a number calculated from the last two digits of the registration number.

## Requirements
- C compiler (GCC)
- Terminal or command prompt

## How to Run

Compile the program:

```bash
gcc readings.c -o readings
```

Run it:

```bash
./readings
```
