TripCalc 🚗⛽


📌 Problem Statement

TripCalc is a simple C programming project that calculates the amount of fuel required and the total fuel cost for a road trip.

The program takes the following inputs:

Total distance to be travelled (in kilometres)

Vehicle mileage (kilometres per litre)

Current fuel price per litre

It then calculates and displays the required fuel and total cost.

🧮 Calculation

The following formulas are used:

Fuel Required = Total Distance / Vehicle Mileage

Total Fuel Cost = Fuel Required × Fuel Price

📥 Input

The user provides:

Total distance to be travelled in kilometres

Vehicle mileage in kilometres per litre

Fuel price per litre

📤 Output

The program displays:

Amount of fuel required for the trip in litres

Total fuel cost

🛠️ Concepts Used

C programming

Variables and data types

User input and output

Arithmetic operations

Floating-point calculation 

▶️ How to Run

Compile the C source file using a C compiler such as GCC and execute the generated program.

gcc tripcalc.c -o tripcalc
./tripcalc

🎯 Objective

The objective of this project is to practice basic C programming concepts, particularly taking user input, performing calculations, and displaying the results.
