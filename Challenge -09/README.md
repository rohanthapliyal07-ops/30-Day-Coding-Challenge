# SEATSMART – Auditorium Seat Reservation System

## About the Project
SEATSMART is a menu-driven C program designed to manage seat reservations for a university auditorium. The auditorium has 5 rows with 8 seats in each row, making a total of 40 seats.

The program allows users to book seats, cancel bookings, reserve seats for groups, and check the auditorium's occupancy.

## Features
- Display all available and booked seats.
- Book an individual seat.
- Cancel an existing booking.
- Reserve consecutive seats for a group.
- Generate an occupancy report.
- Find the busiest row or rows.
- Validate seat numbers and group sizes.

## Concepts Used
- 2D Arrays
- User-Defined Functions
- For Loops
- Do-While Loop
- Switch-Case
- If-Else Statements
- Input Validation

## Seating Representation
- `0` – Available Seat
- `1` – Booked Seat

## How to Run

**1. Compile the program:**
```bash
gcc seatsmart.c -o seatsmart
```

**2. Run the program:**
```bash
./seatsmart
```

## Menu Options
1. Display Seats
2. Book One Seat
3. Cancel Booking
4. Group Reservation
5. Occupancy Report
6. Exit
