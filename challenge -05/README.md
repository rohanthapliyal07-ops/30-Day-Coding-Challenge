# Calculator Program in C

## About
This is a simple menu-driven C program that performs mathematical operations. The user can choose an operation from the menu and continue using it until they select Exit.

## Operations
1. Linear Equation
2. Factorial
3. Quadratic Equation
4. Exit

## How it works
- Linear equation calculates the value of x.
- Factorial calculates the factorial of a number from 0 to 12.
- Quadratic equation finds the roots using the discriminant.
- Exit stops the program.

## Requirements
- GCC compiler
- Math library (`math.h`)

## How to Compile
```bash
gcc calc.c -o calc -lm
```

## How to Run
```bash
./calc
```
